    Pick a product

    For each product family you agree one set of content, in three steps:

    1. Family content: text, use cases, catalogue highlights and the specifications every variant shares, picked from the website, the old Master Catalogue, the new catalogue and the datasheets.
    2. Variant table: what each variant has, and the lines that differ, with one family value (e.g. “5G/4G”) for the website and catalogue.
    3. Preview & approve: see exactly what the website, catalogue and each datasheet will show, fix what the checks find, approve.

    Approving saves one JSON file for the family and one per variant.
